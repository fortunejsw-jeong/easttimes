# East Times (이스트타임즈)

> 속초·고성·양양 영동 북부 3개 시·군을 아우르는 모던 디지털 지역 신문 & 로컬 커머스 플랫폼

## 📰 주요 기능 및 구성

### 1. 와이드 & 트렌디 디지털 뉴스 포털 (`index.html`)
- **실시간 속보 배너 (Breaking News Ticker)**: 긴급 속보 실시간 롤링
- **지역 특화 위젯**: 속초·고성·양양 날씨, 기온, 습도 및 동해안 바다 물때/조석 정보 실시간 표시
- **와이드 헤드라인 벤토 그리드 (Bento Grid)**: 1면 탑기사 및 주요 헤드라인 시원한 비주얼 배치
- **카테고리별 뉴스**: 속초 소식, 고성 소식, 양양 소식, 정치/경제, 사회/문화, 해양/관광
- **PDF 지면 보기 뷰어**: 종이신문 감성의 디지털 호별 지면 뷰어 모달
- **독자 참여 공간**: 독자 투고 / 기사 제보 모달 폼, 시민기자단 모집 안내 및 지원 폼
- **기사 통합 검색**: 제목, 본문, 기자명 검색 기능

### 2. 로컬 상생 이커머스 ('동해 마켓')
- **지역 특산물 판매**: 속초 붉은대게 장, 양양 송이버섯 전통주 키트, 고성 다시마·미역 세트, 설악산 야생화 꿀 등
- **쇼핑몰 풀 기능**: 장바구니 담기, 수량 조절, 실시간 총액 계산, 주문 결제(신용카드/네이버페이/카카오페이/가상계좌) 시뮬레이션 및 영수증 팝업

### 3. 직급별 권한 관리 CMS (`admin.html`)
- **기자 등급 체계 (RBAC)**:
  - `수습기자 (intern)`: 기사 초안 작성 및 데스크 승인 요청
  - `취재기자 (reporter)`: 기사 작성 및 1차 검토
  - `데스크/부장 (desk)`: 기사 검수 및 승인/반려 권한
  - `편집국장 (editor_in_chief)`: 1면 탑기사(Top Lead) 지정, 최종 발행, 기사 삭제, 커머스 주문 관리
- **테스트 계정**:
  - 편집국장: `chief` / `1234`
  - 데스크/부장: `desk` / `1234`
  - 취재기자: `reporter1` / `1234`
  - 수습기자: `intern1` / `1234`

## 🚀 Cloudflare Pages 배포 설정

1. **Cloudflare 대시보드** 접속 -> **Workers & Pages** -> **Create application** -> **Pages** 탭
2. **Connect to Git** 클릭 후 저장소 `fortunejsw-jeong/easttimes` 선택
3. 빌드 설정:
   - **Framework preset**: `None`
   - **Build command**: *(비워둠)*
   - **Build output directory**: `/` (루트)
4. **Save and Deploy** 클릭 시 `https://easttimes.pages.dev` 주소로 즉시 전 세계 CDN 배포 완료
